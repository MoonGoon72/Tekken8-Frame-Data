# TK8 개인정보처리방침

문영균은 TK8: 프레임 데이터 앱의 개인정보 처리 내용을 다음과 같이 안내합니다.

## 1. 앱이 직접 입력받는 정보와 기기 내 저장

앱에는 회원가입이나 로그인 기능이 없으며 이름·전화번호·이메일을 필수로 입력받지 않습니다. 사용자가 작성한 메모는 기기 내에 저장됩니다. 메모 원문과 검색어 원문을 앱의 분석 이벤트로 전송하지 않습니다. 메모 내보내기 파일은 사용자가 선택한 위치나 서비스로 공유되며, 그 서비스의 처리방침이 별도로 적용될 수 있습니다.

## 2. 이용 분석과 원격 설정

앱은 Google Analytics for Firebase로 화면 방문, 캐릭터 선택, 검색어 길이와 결과 수, 필터 사용, 메모 저장 성공 여부, 광고 노출·오류 등의 이벤트를 처리합니다. SDK는 앱 인스턴스 식별자와 기기·앱 정보 등도 처리할 수 있습니다. 앱이 자체 정의한 이벤트에는 메모 내용, 검색어 원문, 사용자 계정 식별자를 넣지 않습니다.

Firebase Remote Config는 광고 표시 여부 등의 앱 설정을 전달하며 Firebase 설치 식별자를 처리합니다. 이용 분석의 목적은 사용성·품질 개선이며 원격 설정의 목적은 앱 기능 운영입니다.

광고 동의 화면에서의 선택은 광고에 관한 선택입니다. 현재 앱에는 Firebase Analytics 수집을 켜고 끄는 별도 사용자 설정이 없습니다. 광고 거절이 분석 수집 중단을 의미하지는 않습니다.

## 3. 광고와 동의 선택

앱은 Google AdMob을 통해 배너와 네이티브 광고를 표시합니다. Unity Ads는 배너 미디에이션 소스로 사용될 예정이며 해당 SDK를 포함한 앱 버전과 미디에이션 활성화 이후 적용됩니다. 네이티브 광고에는 Unity Ads를 사용하지 않습니다.

광고 제공업체의 SDK는 광고 제공·측정·부정 이용 방지 등을 위해 IP 주소, 기기 및 앱 정보, 식별자, 광고 노출·상호작용 정보 등을 처리할 수 있습니다. 실제 항목은 운영체제의 허용 범위, 사용자의 선택과 SDK 설정에 따라 달라집니다. Unity Ads의 초기 도입에서는 개인화 동의를 허용하지 않는 설정을 사용합니다. 비개인화 광고에도 광고 제공과 보안·측정에 필요한 데이터 처리가 있을 수 있습니다.

유럽경제지역·영국·스위스 등 적용 대상 지역에서는 Google의 동의 메시지가 표시될 수 있습니다. 해당되는 경우 앱 설정의 「광고 개인정보 설정」에서 광고 선택을 변경할 수 있습니다. iOS가 허용하지 않은 광고 추적 권한을 앱이 대신 허용하지 않습니다.

## 4. 프레임 데이터와 영상 요청

캐릭터·기술 데이터는 기기 캐시를 우선 이용하고 필요한 경우 Supabase에서 가져옵니다. 기술 영상은 제공되는 버전에서 Cloudflare 저장소로 요청합니다. 이러한 네트워크 요청 시 서비스 제공업체가 IP 주소 등 접속 정보를 처리할 수 있습니다. 앱은 메모 원문을 이 데이터 조회 경로로 업로드하지 않습니다.

## 5. 보관·삭제와 문의

기기 내 메모는 사용자가 앱에서 삭제할 수 있습니다. 직접 내보낸 파일과 운영체제 백업은 해당 저장 위치나 백업 서비스에서 별도로 관리해야 합니다. 앱 삭제만으로 제3자 서비스에 이미 전송된 모든 기록이 즉시 삭제되는 것은 아닙니다.

2026년 10월 4일 확인한 Google Analytics 설정은 이벤트 데이터 2개월, 사용자 데이터 14개월입니다. 새 사용자 활동이 발생하면 사용자 데이터 보관기간을 재설정합니다. 이 설정은 사용자·이벤트 수준 데이터에 적용되며 표준 집계 보고서 전체의 보관기간을 의미하지 않습니다. 원격 설정·광고·접속 기록의 보관과 삭제는 각 서비스의 설정과 정책에 따라 이루어집니다. 개인정보의 열람·정정·삭제·처리정지 등 관련 문의는 운영자에게 연락해 주세요. 직접 식별할 수 없는 SDK 기록은 제공업체의 절차나 추가 확인이 필요할 수 있습니다.
