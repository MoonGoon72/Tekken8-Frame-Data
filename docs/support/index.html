선택한 유형에 맞는 제목과 작성 항목이 메일에 준비됩니다. 내용을 채운 뒤 직접 전송해 주세요.

구매 문의에는 다음 정보를 알려 주세요.

  • Apple 영수증 또는 구매 내역의 주문 ID — 확인 가능한 경우
  • 구매 날짜, 앱 버전, iOS 버전
  • 구매 복원을 시도했는지와 그 결과
  • 표시된 오류와 문제 상황

주문 ID를 찾지 못해도 문의할 수 있습니다. 메일 앱을 사용할 수 없다면 moongoon.cnu@gmail.com으로 직접 보내 주세요.
