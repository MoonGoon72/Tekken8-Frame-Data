# 광고 제거 구매 화면 간소화

2026-10-27 사용자 승인: 설정의 광고 제거 관련 4개 셀을 하나로 통합하고, 구매 화면에는 혜택/1회 결제/실제 가격을 먼저 표시한다. 상세 구매·환불 안내는 별도 화면으로 분리한다.

- 설정에는 ‘광고 제거’ 진입점 하나를 둔다. 구매 완료 시 ‘광고 제거됨’ 상태를 표시한다.
- 기존 PurchaseNoticeViewController는 짧은 구매 화면으로 유지해 메인 안내와 설정의 진입 경로를 재사용한다.
- 제목 ‘광고 없이 기술에 집중하세요’, 설명 ‘하단 배너와 기술 목록 광고가 사라집니다.’, ‘한 번 구매 · 자동 갱신 없음’, StoreKit 실제 가격이 들어간 주 구매 버튼을 제공한다.
- 구매 복원과 ‘구매·환불 안내’는 보조 액션으로 남긴다. 상세 화면에는 구매 적용, 기기 변경/복원, 환불, 약관/문의 섹션을 제공하고 기존 안내 내용/외부 링크를 보존한다.
- 가격/권한 재확인은 오류 시만 제공하며 조회 중에는 표시하지 않는다. 구매자에게는 완료 상태를 보여주고 구매 버튼은 숨긴다. pending/unknown 권한의 기존 구매 방지 및 검증 정책을 보존한다.
- UIKit/iOS 17+, 기존 배경과 tkRed 강조, 한국어/영어, 작은 화면/Dynamic Type/접근성 유지. Analytics/StoreKit/Repository/캐시/버전은 변경하지 않는다.

## 접근 방식

선택한 별도 상세 화면은 긴 설명을 펼쳐도 구매 화면을 밀어내지 않으며 뒤로 돌아갈 때 구매 문맥을 유지한다. 대안은 같은 화면 내 펼치기였으나 사용자와 별도 화면 분리를 선택했다. 전체 설명을 기본 노출하는 기존 방식은 정보의 우선순위가 약해 제외했다.

## 검증

단일 설정 진입, 구매 화면→상세 안내 navigation, 상세 화면의 정보/환불/문의 보존, 가격/실패/조회 중/구매 완료 상태, 구매/복원 회귀 테스트. 320pt/다크 모드/최대 글씨 이미지 확인. 공통 구매 ViewModel을 변경하면 관련 테스트 및 TK8Tests 전체 실행. 기존 온보딩 실패 및 StoreKit 통합 대기 문제는 이번 기능과 분리해 보고한다.
